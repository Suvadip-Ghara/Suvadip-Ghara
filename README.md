# Hi, I'm Suvadip Ghara 👋

### Bioinformatician • Aquaculture Biotechnology • Computational Biology

I build data-driven tools and biological resources at the intersection of **bioinformatics, aquaculture biotechnology, transcriptomics, artificial intelligence, and CRISPR research**.

My work focuses on turning biological data into practical, reproducible resources for fish genomics, health, and sustainable aquaculture.

## Research interests

- 🧬 Transcriptomics, gene expression, and functional annotation
- 🐟 Aquaculture biotechnology and fish genomics
- 🤖 AI-assisted biological analysis and decision-support tools
- 🧪 CRISPR and molecular biotechnology
- 📊 Reproducible computational workflows and research databases
